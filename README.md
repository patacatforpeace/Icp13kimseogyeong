# FreelanceHub — 프리랜서 외주 통합 관리 대시보드

서비스기획 · UI/UX 학원 과제 프로젝트입니다. 프리랜서 디자이너가 여러 클라이언트의
외주 건을 한 화면에서 관리할 수 있는 어드민 대시보드를 기획하고, 작동하는
프로토타입으로 구현했습니다.

- 기획 문서: [`docs/기획서.md`](./docs/기획서.md) — 문제 정의, 페르소나, IA, 유저플로우
- 작동 프로토타입: [`index.html`](./index.html)

## 실행 방법

빌드 도구 없이 브라우저에서 바로 열면 됩니다.

```bash
# 저장소 클론 후
open index.html        # macOS
# 또는 더블클릭으로 열기
```

혹은 간단한 로컬 서버로 실행:

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## 다루는 핵심 문제

1. **여러 클라이언트·프로젝트 현황을 한눈에 파악하기 어렵다** → 대시보드 홈(KPI 요약) + 프로젝트 보드(칸반)
2. **일정·마감 관리가 흩어져 있다** → 마감 캘린더(월간 뷰, 클라이언트별 색상)
3. **정산/인보이스 현황을 추적하기 어렵다** → 정산 관리(청구→입금 상태 추적, 미수금/연체 집계)

## 특징

- 순수 HTML/CSS/JavaScript, 빌드 과정 없이 단일 파일로 동작
- 프로젝트 등록, 상태 변경, 정산 처리가 실제로 동작하며 `localStorage`에 저장되는
  **작동 프로토타입**
- 라이트/다크 모드 대응, 모바일 반응형 레이아웃
- 클라이언트 식별 색상 · 마감 임박도 · 정산 상태를 색상 + 텍스트 라벨로 함께 표시
  (색각 이상 사용자도 상태를 구분할 수 있도록)

## 데모 데이터 초기화

우측 상단 "데모 데이터 초기화" 버튼을 누르면 처음 상태(샘플 클라이언트 5곳,
프로젝트 10건, 인보이스 7건)로 되돌아갑니다.
