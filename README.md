# DueBoard — 외주 프로젝트 태스크 통합 관리

서비스기획 · UI/UX 학원 과제 프로젝트입니다. 클라이언트마다 흩어져 있는
스프레드시트 일정을 하나의 캘린더 + 프로젝트 리스트로 통합하고, 캡처 이미지나
텍스트를 붙여넣으면 구조화된 태스크로 자동 정리해주는 프로토타입입니다.

- 기획 문서: [`docs/기획서.md`](./docs/기획서.md) — 문제 정의, MVP 범위, 데이터 구조, 기술 아키텍처
- 작동 프로토타입: [`index.html`](./index.html)

> Lit(기존 개인용 앱)과는 별개의, 이 과제만을 위한 독립적인 프로토타입입니다.
> 디자인 톤도 Lit의 퍼플 톤을 따르지 않습니다.

## 실행 방법

빌드 도구 없이 브라우저에서 바로 열면 됩니다.

```bash
open index.html        # macOS, 또는 더블클릭
# 또는
npx serve .
python3 -m http.server 8080
```

## 핵심 기능

1. **마감 캘린더** — 첫 화면. 날짜 아래 프로젝트별 색상 마커(원=정상/세모=지연,
   빈값=미완료/채움=완료)로 전체 일정을 한눈에 확인. 날짜 클릭 시 예정일 vs
   실제 완료일 비교.
2. **프로젝트 아코디언 리스트** — 카드에 진행률·태그·정산 상태·다음 게시 D-day.
   펼치면 태스크 표(구분/콘텐츠/사이즈/예정일/상태/비고)에서 완료 처리, 수정
   이력 추가, 정산 상태 변경까지 실제로 동작.
3. **붙여넣기로 추가 (핵심 기능)** — 캡처 이미지 또는 표 텍스트를 붙여넣으면
   자동으로 구조화된 태스크 초안을 만들고, 검수/수정 후 저장.
   - **텍스트 붙여넣기**: 실제로 동작하는 규칙 기반 파서 (탭/콤마 구분 표 인식,
     헤더 매핑, 날짜 형식 정규화)
   - **이미지 붙여넣기**: 🧪 프로토타입 데모 — 실제 이미지 인식 대신 예시
     데이터로 자동완성 (화면에 명확히 표시됨). 실제 서비스 전환 시 Supabase
     Edge Function을 통한 Claude API 연동으로 교체 예정 (`docs/기획서.md` 7장 참고)

## 특징

- 순수 HTML/CSS/JavaScript, 빌드 과정 없이 단일 파일로 동작, `localStorage` 기반
  작동 프로토타입
- 독립적인 디자인 시스템 (퍼플 미사용, 노란기 없는 쿨그레이 배경 + 딥블루 accent)
- 긴급도는 카드 **배경색이 아닌 테두리 색**으로만 표시 (배경 채움 지양)
- 라이트/다크 모드, 모바일 반응형

## 데모 데이터 초기화

우측 상단 "데모 초기화" 버튼을 누르면 처음 상태(샘플 프로젝트 5건)로 되돌아갑니다.
